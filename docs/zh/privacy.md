## 二、我们不会主动收集个人信息

本网站为静态网站，没有联系表单，不需要注册，也没有用户账户。我们不使用 Cookie、分析工具、广告追踪或类似技术。对于访问本网站的访客，我们不会主动收集、存储或处理任何个人信息。

## 三、您主动提供的信息

当您通过邮箱、电话或微信联系我们时，可以选择将姓名、公司、联系方式等个人信息提供给我们。我们仅将这些信息用于回应您的咨询、介绍我们的服务，以及与您就可能的或现有的业务往来进行沟通。

处理的法律依据（GDPR 第 6 条）：您提供信息时的同意（第 6(1)(a) 条），以及我们回应咨询、服务客户所依据的正当利益（第 6(1)(f) 条）；涉及订立合同前步骤时，处理亦属订立或履行合同所必需（第 6(1)(b) 条）。

## 四、托管平台处理的信息（GitHub Pages、Fastly）

本网站托管于 GitHub Pages（GitHub Inc. 的服务，位于美国），并通过 Fastly 的内容分发网络提供访问。您访问本网站时，这些平台可能处理为内容投递、安全和性能所必需的技术数据，包括：

- IP 地址
- 浏览器类型与版本
- 所请求的页面及时间戳
- 设备与网络信息
- 基础的服务器与 CDN 访问日志

这些信息由 GitHub 和 Fastly 依据其自身的隐私政策和服务条款处理。我们不控制这些平台的处理行为，也不对此负责。由于 GitHub 和 Fastly 位于美国及其他司法辖区，此类技术数据可能发生跨境传输。对于从欧洲经济区、英国和瑞士转移的个人数据，GitHub 依据其数据处理协议下的欧盟标准合同条款提供了适当保障。

### 4.1 本地货币显示

当您访问收费标准或服务条款页面时，您的浏览器会向免费地理位置服务（ipwho.is，备选 ipapi.co）发送您的 IP 地址，以识别您来访的国家/地区，并向公开的货币汇率接口获取当前美元汇率，以便本站以您的本地货币显示参考价格。我们不会存储或记录您的 IP 地址，页面仅使用由此得出的国家/地区或货币代码。上述请求由您的浏览器直接向第三方服务发出，第三方所接收的数据（含您的 IP 地址）适用其各自的隐私政策。

## 六、信息披露

我们不会出于营销目的向第三方出售、出租、交换或分享个人信息。特别地，我们不"出售"《加州消费者隐私法案》（CCPA/CPRA）所定义的个人信息。我们仅在以下情形披露个人信息：

- 为提供您要求的服务所必需；
- 为遵守适用法律、法律程序或政府要求；
- 向按照适当保密和数据保护义务代表我们行事的服务提供商披露；
- 经您同意。

## 七、您的权利

根据您所在地区，您可能享有 GDPR 和/或 CCPA/CPRA 赋予的以下权利：

- 访问权——获取我们所持有的您的个人信息的副本；
- 更正权——纠正不准确的个人信息；
- 删除权（"被遗忘权"）——请求删除；
- 限制处理权；
- 数据可携权；
- 反对基于正当利益的处理权；
- 随时撤回同意的权利，且不影响撤回前处理的合法性；
- 向当地数据保护机构投诉的权利。

如果您是加州居民，CCPA/CPRA 还赋予您了解并访问我们所收集个人信息的权利、请求删除的权利，以及行使隐私权利不受歧视的权利。

如需行使上述任何权利，请发送邮件至 jeffrey@bstinspection.com。我们将在适用法律规定的时限内作出回应。

## 八、数据保留

由于本网站没有账户，我们仅保留您发给我们的通讯内容，且仅保留至实现其提供目的所需的时间，或满足法律或合同义务所需的时间。访问日志及类似技术数据由 GitHub Pages 和 Fastly 依其自身政策保存。

## 九、儿童隐私

本网站不面向儿童，我们也不会故意收集任何 12 岁以下儿童的个人信息。如果您认为我们可能收到了 12 岁以下儿童的个人信息，请通过 jeffrey@bstinspection.com 联系我们，我们将采取措施予以删除。

## 十、安全

本网站通过 HTTPS 提供服务。由于网站本身不收集个人信息，访客面临的隐私风险很小。对于您发给我们的任何信息，我们会采取合理的技术和组织措施加以保护。

## 十一、第三方链接

本网站可能链接到外部网站。本隐私政策仅适用于我们的网站，我们不对外部网站的隐私做法负责。
