## 一、总则

1.1 除非广州睿翔技术服务有限公司（以下简称"BST"）另有明确书面约定，BST 提供的所有服务均受以下一般服务条件的约束，这些条件优先于任何采购条款和条件。

1.2 BST 代表委托方（发出指令的实体或个人）执行的服务，将采用允许独立、公正和客观方式的技术和流程进行。服务的最终结果将包括一份证明或文件（以下简称"报告"），传达 BST 被要求提供的信息集合，并将以传真、书面文件或在线报告的形式交付。

1.3 除客户外，任何其他方均无权向 BST 发出指令，特别是关于检验范围或报告交付的指令，除非获得客户授权。

## 二、服务的提供

BST 作为独立第三方，以查明或建议的形式提供信息，其特殊目的是帮助预防服务受益方所面临的风险，并帮助他们确保产品质量。BST 的服务（以下简称"服务"）包括 BST 执行的工作，包括但不限于：

- 工厂审核 (FA)
- 社会责任审核 (SCA)
- 初期生产检查 (IPC)
- 过程质量控制 (IPQC)
- 生产中期检查 (DUPRO)
- 最终随机抽样检验 (FRI)
- 装柜监督 (L/S)
- 测试安排 (TA)

## 三、检验条款和条件

| | |
|---|---|
| **预订提前期** | 应在预定检验日期前至少 3 个工作日提出服务请求。少于 2 个工作日的预订可能无法按时完成。 |
| **延迟预订** | 在请求服务日期前一个工作日（正常工作日）以内的延迟预订，如工作量允许将予以执行。 |
| **最终检验数量** | 最终检验通常在货物 100% 生产完成且至少 80% 包装完毕时进行。低于此限度的最终检验可能可以执行，但必须由客户书面确认。 |
| **人工天** | 一人工作及/或出差一个正常工作日。最低收费为 1 个人工天——按与客户约定执行。 |
| **正常工作时间** | 工作及往返服务地点的时间总和。正常工作时间为每天 8 小时。仅工作时间超过 8 小时时将适用加班费。 |
| **加班费** | 正常工作时间以外的工作时间——25 美元/人工小时。 |
| **差旅时间收费** | 1. 如差旅与服务同日进行，即使超过正常工作时间，差旅时间免费（但须遵守当地劳动法）。2. 如需在服务日期前一日或后一日差旅，则需收取差旅费。——最多 4 小时：加收 0.5 个人工天。3. 因交通资源不足而在服务日期前一日或后一日的等待时间。——超过 4 小时：加收 1.0 个人工天。 |
| **正常工作天数** | 周一至周五 |
| **节假日工作收费** | 周六或同等假日 = 每人工天附加费 100 美元；周日、公共假日或同等假日 = 每人工天附加费 150 美元。 |
| **变更服务日期费** | 在服务日期前不足 1 个工作日通知要求重新安排初始服务日期。——附加费 50 美元。 |
| **延迟变更服务日期费** | 在服务当日要求重新安排初始服务日期。——人工天费率 + 任何已发生的费用。 |
| **延迟开始费** | 要求下午或晚上开始服务。——每人工天附加费 50 美元。 |
| **延迟取消费** | 在服务日期前不足 1 个工作日取消服务。——人工天费率 + 任何已发生的费用。 |
| **缺失服务费** | 当验货员到达时货物未准备好或所需数量无法进行检验。——人工天费率 + 任何已发生的费用。 |
| **复检费** | 根据客户要求。——人工天费率 + 任何已发生的费用。 |
| **差旅费** | 交通费用——按实际费用收取。 |
| **住宿费** | 如需在服务日期前一日/后一日差旅或订单需要 2 天以上时，将收取住宿费。——按实际费用收取。 |
| **邮寄费** | 文件、样品、材料等。——按实际费用收取。 |
| **责任** | 参照 BST 的协议——服务费的 3 倍，特殊情况下最高 10 倍。 |

## 四、BST 的义务和承诺

BST 明确保留自行决定接受或拒绝服务请求的权利，不得因以下原因被迫接受或对拒绝服务请求或产品承担责任：

- 超出其活动范围或专业领域。
- 存在地理可及性问题，例如在受限或高度偏远区域提供服务或产品。
- 要求 BST 获得特殊许可才能运营，例如政府许可。

BST 承诺以专业和及时的方式提供其已接受执行的服务，符合适当的专业实践，并遵守：

- 客户在订购服务时发出的并经 BST 确认的特殊指令——委托范围应由客户和 BST 正式签署，如无此类指令：
- 任何相关的专业标准、贸易惯例、用法或实践。
- BST 基于技术、操作和/或财务考虑认为合适的方法。

BST 应在选择和分配其人员时尽职尽责并运用专业技能。

## 五、客户的义务和承诺

客户同意：

5.1 采取一切合理措施确保 BST 能够接触到服务所依据的材料；

5.2 及时（无论如何不迟于预定服务前 48 小时）向 BST 提供所有信息、样品以及完成所请求服务所需的文件，但一般可用文件（如规范和标准）除外，可通过客户或其供应商或代理人提供。

5.3 确保及时向 BST 提供充分的指示和通知，以便于正确执行所请求的服务。

5.4 告知 BST 服务的开始或恢复日期，以及影响接受服务的项目的重要日期。

5.5 通常向 BST 提供一切合理协助，提供必要的指示、信息、文件、安全和安保信息，涉及工作条件、所需设备和访问权限（视情况而定）。

5.6 反映客户与第三方之间约定的文件或第三方的文件——如由 BST 收到，仅视为参考信息，不延伸或限制 BST 接受的服务范围或义务。

## 六、责任与赔偿

### 6.1 责任限制

BST 的任何行动或检验均不免除制造商交付优质货物的责任或赔偿客户交付劣质产品的责任。BST 执行的检验只是买方为更好地控制采购过程、减少错误、误解、疏忽甚至欺诈的可能性而使用的质量工具组合。如能证明 BST 的员工在检验过程中未注意到已记录的缺陷或安全问题，BST 将退还检验费用，在经证实的极端故意不当行为情况下，最高赔偿十倍。客户对 BST 员工表现的任何疑虑应立即告知 BST，以便 BST 启动索赔调查，包括检查参考样品、出货样品以及与检验相关的所有文件，以确定问题所在。

BST 的建议仅针对客户提供的文件和信息提出，如 BST 收到不完整或虚假信息，BST 不承担责任。

### 6.2 赔偿

6.2.1 如果 BST 因任何性质的损失、损害或费用索赔而承担责任，无论其如何产生，其对客户的责任在任何情况下均不超过为提出索赔的特定服务支付的总费用总额的十倍。

6.2.2 此外，对于最终随机检验服务，如果生产完成率低于 100%，我们的责任仅限于检验时已完成的物品。FRI 报告不证明出货。

## 七、其他

BST 及其子公司和/或关联公司与客户承诺不向任何第三方披露从对方获得的有关 BST 服务执行的机密信息。

BST 应尽力妥善保管样品。但客户不得就因火灾、水灾或盗窃造成的样品丢失，或因在检验过程中使用样品而导致的样品直接/间接损害提出赔偿要求。
